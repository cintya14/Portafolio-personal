# Requisitos: Portafolio personal

## Objetivo
Mostrar los proyectos que voy construyendo mientras aprendo desarrollo
de software, para que otras personas vean mi trabajo y mi evolución.

## Público
(todos)

## Secciones de la página
- Inicio (nombre, frase de presentación, correo, botón de CV, redes)
- Sobre mí
- Proyectos
- Educación
- Skills
- Contacto

## Qué puede hacer un visitante
- Ver una presentación breve sobre mí.
- Ver la lista de mis proyectos.
- Abrir el detalle de un proyecto (descripción, tecnologías, aprendizajes).
- Ir al código en GitHub o a la demo de cada proyecto.
- Encontrar mis datos de contacto.

## Fuera de alcance por ahora
- Blog
- Formulario de contacto
- Panel privado para administrar proyectos
- Multilenguaje

## Estilo visual
- Referencia: portafolio de una sola página con menú lateral,
  tema oscuro, tipografía monoespaciada y colores de acento.
- Debe adaptarse bien al celular.

## Entidades
### Proyecto
- título, descripción corta, descripción larga, tecnologías,
  enlace al código, enlace a la demo, imagen, fecha

### Perfil
- nombre, resumen, correo, enlaces a redes
